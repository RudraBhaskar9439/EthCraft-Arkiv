Why use Arkiv here?

Another client can query the same owned, expiring records without access to EthCraft’s database or its running backend. Worker, namespace and revision filters make the shared state discoverable. Handoffs read the published entity before work continues.

Owner approval, the private objective, wallet permissions and native custody stay on the game server. The receiving agent checks its own supplies and the world. A progress record never grants spending or execution authority.
