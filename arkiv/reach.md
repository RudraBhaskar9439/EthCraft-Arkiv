# Reach and trial scope

Intended users are Minecraft server operators and players switching work between AI providers. A player can inspect observed task progress, pause one worker and ask another to continue using the shared progress record. Other clients can read the same records without running the game's backend.

Actual scope is one local EthCraft deployment, two worker slots and controlled qualification clients. There is no measured external adoption, retention, demand or independent-human handoff study. Controlled public fixtures are marked in their payloads and on the board. The command-line query in `README.md` is runnable today with the committed namespace and publisher, while the entities exist. The public graphical board is hosted separately at https://ethcraft-arkiv.quiet-buddy-9104.chatgpt.site and does not require the laptop backend. The original localhost board remains available to the player.

The portable schema and independent read are the useful continuation point after the event. Multi-server write interoperability, independently owned worker publications, an external user pilot remains future work; they are not requirements claimed complete by this implementation.
